# ☀️ Режим дня — дитячий розклад зі звуками

Веселий розклад дня для діток: кожна подія зі своїм звуком і яскравою анімацією.

## Як запустити на Vercel (2 хвилини)

**Варіант 1 — через термінал (найшвидше):**
1. Розпакуй цю папку на компʼютері.
2. У терміналі перейди в папку: `cd kids-routine`
3. Виконай: `npx vercel`
4. Увійди у свій Vercel-акаунт, на питання відповідай Enter (налаштування за замовчуванням).
5. Готово — отримаєш посилання на кшталт `https://kids-routine.vercel.app` 🎉

**Варіант 2 — через сайт vercel.com:**
1. Залий папку в свій GitHub-репозиторій.
2. На vercel.com натисни Add New → Project → обери репозиторій → Deploy.

## Як користуватись
- Відкрий посилання на телефоні/планшеті.
- Натисни «📱 Тримати екран», щоб сторінка не гасла.
- «⚙️ Налаштування» — зміни час, назви, емодзі та звуки; можна завантажити свої звуки (до 2.5 МБ).
- Коли настає час події — лунає звук і зʼявляється великий веселий екран. Кнопка «Готово! ✅» вимикає.

## Важливо
- Звук працює, поки сторінка відкрита. На заблокованому iPhone браузер не може будити звуком (обмеження iOS).
- Для iPhone: додай сторінку на домашній екран (Поділитись → На екран «Додому») — буде як окремий додаток.
- Розклад зберігається в браузері пристрою (localStorage).

## Додавання події за посиланням
Відкрий посилання виду:
`https://твій-домен.vercel.app/#add=1&time=14:30&name=Помити%20посуд&emoji=🍽️&sound=fanfare`
— і подія автоматично зʼявиться в розкладі (без дублікатів при повторному відкритті).
Параметри: `time` (ГГ:ХХ, обовʼязково), `name`, `emoji`, `sound` (sunrise, yummy, play, sleep, fanfare).
